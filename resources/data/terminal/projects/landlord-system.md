# Landlord Management System

**Stack:** Laravel, Alpine.js, Tailwind CSS, SQLite/MySQL

**Status: Work in Progress**

A property management platform designed to streamline landlord-tenant relationships, maintenance requests, and rent tracking.

## Planned Features

- Property and unit management (add, edit, archive)
- Tenant portal: view lease, submit maintenance requests
- Rent payment tracking and reminders
- Document storage (lease agreements, inspection reports)
- Landlord dashboard with occupancy and payment overview

## Current Progress

- Database schema designed
- Laravel authentication scaffolding complete
- Property CRUD implemented
- Tenant management in progress

## Technical Notes

Multi-tenancy architecture: each landlord account is isolated. Built with Laravel Policies for authorisation.
