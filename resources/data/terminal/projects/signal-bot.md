# Signal E-Commerce Bot

**Stack:** Python, Signal Bot API, REST APIs

An automated e-commerce shop bot built on the Signal messaging platform, enabling product browsing, ordering, and payment flows directly within Signal chats.

## Features

- Product catalogue browsing via chat commands
- Order creation and management
- Payment flow integration
- Admin panel for inventory updates
- Notification system for order status updates

## Technical Notes

Built from scratch using Signal's unofficial bot API. The bot handles inbound messages, parses commands, and responds with formatted product listings and order confirmations.

## Why Signal?

Signal's end-to-end encryption made it an interesting platform for private commerce. The project was a technical challenge to build a full e-commerce flow within the constraints of a messaging API.
