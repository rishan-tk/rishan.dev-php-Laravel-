# Movie Database

**Stack:** PHP, HTML5, CSS3, MySQL, JavaScript

A full-stack web application for browsing, searching, and reviewing films. Built as an academic project at the University of East Anglia.

## Features

- Search movies by title, genre, or release year
- User ratings and reviews
- Detailed movie pages with cast, synopsis, and trailers
- Responsive design for mobile and desktop
- User accounts with watchlist functionality

## Database Design

Normalised MySQL schema with tables for movies, genres, users, ratings, and reviews. Optimised queries using indexed foreign keys.

## Academic Context

Built as part of the Web Technologies module. Graded for database design, code quality, and UI/UX.
